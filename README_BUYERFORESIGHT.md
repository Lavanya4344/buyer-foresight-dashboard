# BuyerForeSight User Directory Dashboard

## 📌 Overview
This project is a User Directory Dashboard built using React. It fetches user data from an API and displays it in a table with search, sorting, and detailed view functionality.

## 🚀 Features
- View users in a table
- Search users by name or email
- Sort users by Name and Company
- Click on a user to view full details

## 🛠️ Tech Stack
- React
- React Router
- JavaScript
- HTML/CSS

## 🔗 API Used
https://jsonplaceholder.typicode.com/users

## ▶️ How to Run
```bash
npm install
npm start
